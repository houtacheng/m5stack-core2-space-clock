# M5Stack Core2 Space Clock

Native firmware that turns an M5Stack Core2 into a smooth animated clock,
20-alarm clock, meditation timer, emotion-observation logger, MQTT device and
four-page Bitfocus Companion Satellite control panel. Version 2.9.8 restores
verified HTTPS login to the emotion database, adds a live database connection
indicator, locks entry until authentication succeeds, and refines all eight
emotion-observation pages plus their on-device reminder settings. OTA preserves
saved Wi-Fi, MQTT, alarm and API settings. Version 2.9.7 repaired empty Chinese
glyph bitmaps and restored the PSRAM-enabled Matrix rain build.

See [SpaceClockNative/README.md](SpaceClockNative/README.md) for setup, features,
building and OTA update instructions. The ready-to-install image is published at
`firmware/SpaceClockNative-OTA.bin`.
